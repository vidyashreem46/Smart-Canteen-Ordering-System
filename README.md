# 🍽️ Smart Canteen Ordering System

A digital food ordering and order tracking system designed to reduce waiting time and improve the overall canteen ordering experience.

The system allows customers to scan a common QR code, select their table, browse the digital menu, place orders, track order status, make payment selections, and receive a digital bill.

It also provides separate workflows for kitchen staff, waiters, and administrators.

---

## 📌 Project Overview

Traditional canteen ordering often involves:

- Long queues
- Manual order taking
- Miscommunication between customers and kitchen staff
- Difficulty tracking order status
- Manual bill generation
- Difficulty maintaining sales records

The **Smart Canteen Ordering System** provides a simple digital solution for these problems.
